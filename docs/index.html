⚠️ Important: CORS Limitation

This web app makes direct API calls to Spond from your browser. Due to CORS (Cross-Origin Resource Sharing) restrictions, this may not work in all browsers or configurations.

If the app hangs or fails to load data:

  • Option 1: Install a CORS browser extension (search for "CORS Unblock" or "Allow CORS" in your browser's extension store)
  • Option 2: Use the Python CLI tool instead (no CORS restrictions)

CORS Workarounds

What is CORS? CORS is a security feature in browsers that prevents websites from making requests to different domains. Spond's API doesn't allow browser-based requests from GitHub Pages.

Solution 1: Browser Extension (Easiest)

  1. Install a CORS extension for your browser:
    • Chrome/Edge: "Allow CORS: Access-Control-Allow-Origin" or "CORS Unblock"
    • Firefox: "CORS Everywhere" or "Allow CORS"
  2. Enable the extension (click its icon in your browser toolbar)
  3. Reload this page and try again
  4. Important: Disable the extension when not using this app for security

Solution 2: Python CLI Tool (Recommended)

The Python command-line tool has no CORS restrictions and works reliably. See the installation guide.

Solution 3: Local Development Server

Run the web app on a local server that can proxy requests to avoid CORS. This requires technical setup.

To use this app, you need a bearer token from Spond. How to get a bearer token?

How to get your bearer token:

  1. Log in to club.spond.com in your browser
  2. Press F12 to open Developer Tools
  3. Click the Network tab
  4. Refresh the page
  5. Click on any request to api.spond.com in the list
  6. Look for the Authorization header on the right side
  7. Copy the long string after "Bearer " — that's your token

⚠️ Keep your bearer token private! Don't share it with anyone.
