🧪 Testing the Web App

To test the web app:

  1. Open index.html in your browser
  2. You'll need a valid Spond bearer token to load real data
  3. Alternatively, use the "Fetch Clubs" feature to verify API connectivity

Note: The app makes direct API calls to Spond's servers. CORS restrictions may apply depending on your browser and Spond's API configuration.
